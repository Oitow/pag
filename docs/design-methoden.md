# Design-Methoden

Ablauf: **Zielgefühl (MDA) → Zielgruppe → Pillars → Core Loop → Prüfung (SDT, Flow) → Prototyp → Playtest**

## 1. MDA-Framework (Hunicke, LeBlanc, Zubek)
Rückwärts vom Gefühl zur Regel:
- **Aesthetics:** Welches Gefühl soll der Spieler haben? (Entdecken, Meistern, Ausdruck …)
- **Dynamics:** Was passiert dabei im Spiel?
- **Mechanics:** Welche konkreten Regeln erzeugen das?

## 2. Spielertypen
- **Bartle:** Achiever, Explorer, Socializer, Killer
- **Quantic Foundry (Yee):** 12 Motivationen, z. B. Strategie, Zerstörung, Design, Story, Vollständigkeit

## 3. Self-Determination Theory (Ryan & Deci)
Jede Mechanik prüfen auf:
- **Kompetenz:** Werde ich besser?
- **Autonomie:** Treffe ich echte Entscheidungen?
- **Verbundenheit:** Mit anderen oder mit der Welt

## 4. Core Loop
Die sich ständig wiederholende Schleife, in einem Satz erklärbar.
Beispiel: Kämpfen → Loot → Stärker werden → Schwerere Gegner

## 5. Flow (Csikszentmihalyi)
Herausforderung wächst mit dem Können. Bestimmt die Schwierigkeitskurve.

## 6. Design Pillars
3–4 Grundsätze, an denen jede Entscheidung gemessen wird.

## 7. Prototyp und Playtest
Kleinen Prototyp bauen → Spieler beobachten → Daten messen (Spieldauer, Abbruchpunkte) → verbessern.
