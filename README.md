# PAG – Mini-Kopf

Zentrale Sammlung für Ideen, Spiele, Tests, KI-Prompts, Skills, Methoden und Optimierungen.
Alle Spiele: Single-File HTML/JS/CSS, mobil-tauglich, keine Build-Steps.

## Struktur

| Ordner | Inhalt |
|---|---|
| `ideas/` | Spielideen und Konzepte |
| `games/` | Spiele, je eins mit eigenem Ordner und `index.html` |
| `tests/` | Testlabs und Benchmarks |
| `ki/` | Prompts und Modellvergleiche |
| `skills/` | Wiederverwendbare Anleitungen |
| `docs/` | Methoden und Wissen (Game Design, UX) |
| `patches/` | Optimierungen und Changelogs |
| `dashboard/` | Später: Übersicht im Matrix-/3D-Stil |
