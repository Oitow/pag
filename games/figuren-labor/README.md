# 🧍 Figuren-Labor

Testgelände für das Figuren-System der Engine (`docs/FIGUREN-SYSTEM.md`): Aussehen bearbeiten, herumlaufen, NPCs beobachten.

- 👕 Aussehen: 8 Vorlagen, Zufalls-Looks (auch Kinder), alle Stile/Farben/Körperbau live; wird im Browser gespeichert
- Gelände zum Ausprobieren: Treppe + Plateau (Stufen hochgehen), steile Rampe (rutschen), Teich (schwimmen), Bäume/Felsen (Hindernisse)
- 8 NPCs: einer folgt dir (und winkt), einer läuft eine Runde, der Rest wandert
- 🎬 Aktionen: alle Animations-Clips (winken, schlagen, hacken, werfen, tanzen, tod …)
- ℹ️ Debug-Anzeige: Tempo, Zustand, Schritte

## Steuerung
WASD/Pfeile laufen · Shift Sprint · Leertaste springen · C ducken · Ziehen = Kamera · Rad = Zoom · F Schlag · G winken.
Handy: Stick links (erscheint unter dem Finger), rechts ziehen = Kamera, zwei Finger = Zoom, Knöpfe unten rechts. Gamepad geht auch.
